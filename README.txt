JOKER IPTV Android PWA prototype

This is a mobile-first web app prototype, installable as a PWA on Android when served over HTTPS. It is not a native APK.
Features: theme toggle, M3U URL loading/parsing, channel search, favorites, and basic HTML video playback.\nNote: IPTV source hosts may block browser fetches with CORS. The prototype currently loads M3U URLs directly from the browser. HLS playback depends on Android browser support and stream format.

To install on Android: host the folder on an HTTPS site, open it in Chrome, then menu > Install app / Add to Home screen.
